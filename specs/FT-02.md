# FT-02 Input Berat & Notifikasi Min. Charge

Sumber PRD: Bagian 5 (BL-01), Bagian 6 (FT-02), Bagian 8 (AC-01), Bagian 9 (TC-01, TC-03), Bagian 11 (`store_info.minimum_charge_kg`)

## Tujuan
Pengguna dapat memasukkan estimasi berat cucian dalam kilogram dan langsung melihat pemberitahuan otomatis apabila aturan berat minimum 3 kg berlaku.

## Alur
1. Pengguna mengetuk kolom estimasi berat (bermula kosong).
2. Pengguna mengetik angka berat memakai koma atau titik desimal (misalnya `1,8` atau `4.5`).
3. Jika berat valid dan kurang dari 3 kg, kotak pemberitahuan *minimum charge* langsung tampil di bawah kolom.
4. Jika berat 3 kg atau lebih, pemberitahuan *minimum charge* tidak muncul dan berat ditagih sama dengan berat aktual.

## Data
- `STORE_INFO.minimum_charge_kg` (`3.0`)

## Aturan dan rumus
- Input menerima koma (`,`) dan titik (`.`) sebagai pemisah desimal; spasi awal dan akhir diabaikan.
- Nilai berat aktual valid adalah angka desimal `>= 0.1` (dibulatkan ke 1 angka di belakang koma saat diperlukan tampilan, atau dipakai langsung pada perkalian lalu hasil rupiah dibulatkan ke bilangan bulat terdekat `Math.round`).
- Rumus berat ditagih: `W_ditagih = Math.max(STORE_INFO.minimum_charge_kg, W_aktual)` bila `W_aktual >= 0.1`.
- Jika input kosong atau `<= 0` atau bukan angka valid, berat ditagih bernilai `0` (belum ada biaya yang dihitung).

## Input dan validasi
- Kolom input wajib diisi (`inputMode="decimal"`, label selalu terlihat).
- Saat tombol kirim ditekan:
  - Jika kosong, `<= 0`, atau bukan angka valid: tampilkan error di bawah kolom, contoh: `"Masukkan estimasi berat minimal 0,1 kg, contoh: 2,5"` dan pindahkan fokus ke kolom berat bila ini error pertama.
  - Jika `0 < W_aktual < 0.1`: tampilkan error `"Estimasi berat minimal 0,1 kg, contoh: 0,5"`.

## Tampilan dan teks
- Label kolom: `Estimasi Berat Cucian (kg)` dengan teks bantuan `Minimal 0,1 kg (bisa pakai koma atau titik)`.
- Notifikasi visual otomatis saat `0.1 <= W_aktual < 3.0`: kotak informasi dengan ikon info dan teks `Ketentuan minimum charge 3 kg berlaku. Berat ditagih menjadi 3 kg.`

## Kasus uji
| ID | Input | Hasil yang diharapkan | Sumber |
| :--- | :--- | :--- | :--- |
| AC-01 / TC-01 | Berat `2.0` kg, layanan `L01` (Rp 6.000/kg), tanpa add-on | Berat ditagih `3 kg`, notifikasi minimum charge tampil, subtotal `Rp 18.000`. | PRD AC-01 & TC-01 |
| TC-03 | Berat kosong atau `0` kg saat submit | Validasi gagal, pesan error tampil di bawah kolom berat, tidak membuka WhatsApp. | PRD TC-03 |
